# galeria
GALERIA (Galeri Sistem Informasi dan Aplikasi untuk BPS se-Provinsi Bengkulu) merupakan sistem informasi yang dikembangkan sebagai pusat inventarisasi, dokumentasi, dan berbagi informasi mengenai sistem informasi serta aplikasi yang dikembangkan oleh BPS Provinsi Bengkulu dan BPS Kabupaten/Kota.
